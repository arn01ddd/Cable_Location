Cable Location 2.2.1 brings a navy dark appearance to the redesigned workspace.

- Near-black sidebar, deep navy panels, pale text, and soft blue accents.
- Dark destination, session, Diagnostics, device picker, and native controls.
- Clear blue primary actions and distinct amber restoration states.
- Readable generic **Latitude, Longitude** hint, validation messages, and disabled controls.
- Stronger field/button boundaries and expanded contrast checks using the shared palette.

Release verification includes 16 backend tests, 74 native assertions, five
native UI previews, a dependency advisory audit, and signature/checksum checks.

Download **CableLocation-macOS-arm64.zip**, extract it, and open **Cable Location.app**.
Requires an Apple silicon Mac with macOS 14 or later and Python 3.10 or later.
First launch downloads the private Python backend. The app is ad-hoc signed
without Apple Developer ID notarization.

No physical iPhone was available for this update. Verify location and restoration
in Maps on your iPhone.
